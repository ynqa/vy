## Open help

Run `:help` or `:h` to open help. It takes no arguments and is available in the input, *focus*, and *jaq* views.

Scroll with `j` / `k`, the arrow keys, or page navigation, and press `Esc` to return to the original view. Help reflects any keybindings changed in your settings.

See the [command reference](../../reference/commands.md) and [keybinding reference](../../reference/settings/keybindings.md) for the lists in the documentation.
